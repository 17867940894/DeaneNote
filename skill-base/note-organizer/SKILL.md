## 2. 双链（wikilink）完整性（最重要）

- 链接格式：`[[笔记名]]`、`[[笔记名|别名]]`、`[[路径/笔记名#标题]]`、`[[笔记名#^块id]]`
- **改文件名 / 移动文件前，必须确认双链同步**。本环境使用 Obsidian 官方 CLI（`obsidian` 命令，Obsidian 1.13+，需客户端保持运行）：`rename` / `move` 由应用内执行，会自动 safe-refactor 更新全库 `[[旧名...]]`；内容修改走 `obsidian eval`（或 `create ... overwrite`），不要直接读写磁盘 md。若 Obsidian 未运行，CLI 不可用，需手动 `grep` + 逐文件替换（注意：Read/Grep 工具可能读到过期沙箱快照，裁定"文件到底改没改"以 bypass 终端读真实磁盘为准）。
- 历史漂移链接均已修复（见 `测试笔记/00-知识地图.md`）：
  - `软件测试基础/selenium/01-原理与安装` → `自动化测试/Selenium全栈笔记/01-基础笔记/01-环境搭建`
  - `软件测试基础/jMeter/JMeter 快速上手` → `JMeter/jmeter性能测试`（注：`JMeter 快速上手` 从未建文件，2026-08-06 复核后统一指向 `jmeter性能测试`）
  - `Python/Python基础`（原指向文件夹）→ `Python/Python基础/Python基础`
  - 2026-08-06 双链清理专项（已完成）：Selenium 旧命名 `0N-名称` → `N. 名称`（如 `02-选择元素的基本方法` → `2. 选择元素的基本方法`）；Swing 已删笔记的相关链接移除 / 概念词还原（`12-事件监听` → `事件监听`）；`JMeter 快速上手` → `jmeter性能测试`（原名从未存在）；`Spring 学习笔记`、`Mybatis 课堂笔记` 空格笔误修正；无对应笔记的日期链接（如 `2026-07-06`）转纯文本；`软件测试基础/Day01~04/day0X课堂笔记.md` 占位笔记补齐。

## 3. 命名约定

- 章节 / 有序笔记用 `NN-名称.md`（如 `01-环境搭建.md`），便于排序与 MOC 引用。
- 文件夹与笔记用中文；英文专有名词保持原样（Selenium、JMeter、Fiddler…）。
- 避免重复同名笔记：新笔记命名前先搜索是否重名，同名请用路径区分或加前缀。

## 4. 新增笔记流程

1. 在对应学科目录建 `NN-名称.md`（或一个原子笔记）。
2. 引用旧知识：用 `[[...]]` 链接相关概念，别重复解释。
3. 回到对应 MOC（`00-知识地图.md` 或学科 MOC）补一条入口链接。
4. 图片就近放 `assets/`，用 `![[...]]` 引用。

## 5. 安全

- `config.md` 存明文凭据，已被 `.gitignore` 忽略，但仍在本地磁盘。**建议**：迁移到系统密钥库 / 环境变量，或至少移出仓库；相关密码应定期轮换。在 AI 对话中绝不要读取或回显它。
