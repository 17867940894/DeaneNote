# 学习成果总览

> 汇总在软件测试学习与项目实践中积累的知识，按模块分点列出，仅作简要说明。
> 主方向：**软件测试 + Java 后端**，JavaScript / Python 为辅，AI 提效为延伸。

## 一、软件测试基础

- 测试定义与目的、软件生命周期模型（瀑布 / V 模型等）
- 测试用例设计方法：等价类、边界值、场景法、判定表等
- 缺陷管理流程与质量模型（ISO / 软件质量特性）
- Web 协议基础：HTTP、URL、OSI 七层、TCP/IP、抓包与请求分析

## 二、接口测试

- **Postman**：集合管理、变量系统、前置/测试脚本断言、请求串联、数据驱动、Newman + CI、Mock
- **Apifox**：前置/后置/公共脚本、pm 脚本 API、JS 类库、响应数据可视化、调用外部程序
- **抓包工具**：Fiddler（HTTPS 解密）、Wireshark（协议分析）、浏览器 DevTools
- **ECMobile / Ecshop 接口测试实践**：主档 40+ 接口、精炼 16 接口文档梳理；公共约定（Base URL、x-www-form-urlencoded、`json=` 参数、session uid/sid 认证）

## 三、自动化测试

- **Selenium**：元素定位八大方式、等待机制、弹窗/iframe 切换、鼠标键盘操作、PO 模式、多浏览器兼容、文件上传下载、截图日志、JS 执行、滑块验证码、并发测试、参数化与数据驱动、异常捕获
- **pytest + Selenium 实战**：RuoYi 3.9 后台管理系统测试
- **Python Playwright**：定位器、自动等待、断言、API 测试、身份验证、Mock API、Trace 调试、CI 集成、Chrome 扩展
- **组卷自动化系统**：日常运行维护、跨天题目去重、错题变体重现调试

## 四、性能测试

- **JMeter 5.6.3**：性能指标（TPS、响应时间、并发）、接口压测、录制、命令行执行、报表分析、插件扩展
- **BlazeMeter / Taurus**：YAML 配置转 JMeter .jmx 脚本的压测工作流
- LoadRunner 基础知识了解

## 五、移动 APP 测试

- 安卓测试环境搭建、模拟器使用、系统结构认知
- **ADB 一键命令合集**：常用调试命令
- 移动测试常见问题记录与练习计划

## 六、数据库与 SQL
