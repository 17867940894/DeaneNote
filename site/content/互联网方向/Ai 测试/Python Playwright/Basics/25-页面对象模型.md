# 页面对象模型 (Page Object Model)

## 简介

大型测试套件可以进行结构化，以优化编写和维护的便捷性。页面对象模型（POM）就是这样一种组织测试套件的方法。

* **定义**：页面对象代表了 Web 应用程序的一部分。例如，一个电子商务 Web 应用可能包含主页、商品列表页和结账页，每个页面都可以由一个页面对象模型来表示。
* **优势**：
* **简化编写**：通过创建更高级别的 API，使代码更贴合应用程序业务逻辑。
* **简化维护**：将元素选择器集中在一处并创建可重用代码，避免代码重复。


---

## 实现方式

页面对象模型是对 Playwright [Page](https://playwright.cn/python/docs/pom#) 的封装。

### 1. 定义页面对象类 (`models/search.py`)

**同步 (Sync)**

```python
class SearchPage:
    def __init__(self, page):
        self.page = page
        self.search_term_input = page.locator('[aria-label="Enter your search term"]')

    def navigate(self):
        self.page.goto("https://bing.com")

    def search(self, text):
        self.search_term_input.fill(text)
        self.search_term_input.press("Enter")
```

**异步 (Async)**

```python
class SearchPage:
    def __init__(self, page):
        self.page = page
        self.search_term_input = page.locator('[aria-label="Enter your search term"]')

    async def navigate(self):
        await self.page.goto("https://bing.com")

    async def search(self, text):
        await self.search_term_input.fill(text)
        await self.search_term_input.press("Enter")
```
