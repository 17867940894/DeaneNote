# 快照测试 (Snapshot Testing)

> [!note]
>
> **[Aria 快照](https://playwright.cn/python/docs/aria-snapshots)** 就是一张**纯文本形式的网页无障碍骨架图**，用来帮开发人员快速检查网页的核心功能和结构有没有被改坏。

## 概述

通过 Playwright 的快照测试，您可以根据预定义的快照模板断言页面的可访问性树。

**同步 (Sync)**

```python
page.goto('https://playwright.cn/')
expect(page).to_match_aria_snapshot("""
  - banner:
    - heading /Playwright enables reliable end-to-end/ [level=1]
    - link "Get started":
      - /url: /docs/intro
    - link "Star microsoft/playwright on GitHub":
      - /url: https://github.com/microsoft/playwright
    - link /[\\d]+k\\+ stargazers on GitHub/
""")

```

**异步 (Async)**

```python
await page.goto('https://playwright.cn/')
await expect(page).to_match_aria_snapshot("""
  - banner:
    - heading /Playwright enables reliable end-to-end/ [level=1]
    - link "Get started":
      - /url: /docs/intro
    - link "Star microsoft/playwright on GitHub":
      - /url: https://github.com/microsoft/playwright
    - link /[\\d]+k\\+ stargazers on GitHub/
""")

```

## 断言测试与快照测试对比

| 测试类型 | 适用场景 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **断言测试** | 核心逻辑验证、计算值测试、精确条件判断 | 意图明确、特异性强、调试反馈直接 | 复杂输出编写繁琐、维护开销大 |
| **快照测试** | 页面 UI/组件整体结构、复杂 UI 结构、回归测试 | 简化复杂输出比较、反馈快速、保证一致性 | 易过度依赖、微小改动引发大范围报错 |

## Aria 快照语法规则

ARIA 快照使用 YAML 格式描述无障碍元素的层次结构，节点基本格式为：`- role "name" [ attribute=value ]`

* **role**：元素的 ARIA 或 HTML 角色（如 `heading`、`button`、`list`）。
* **"name"**：无障碍名称。支持字符串精准匹配或正则表达式（如 `/patterns/`）。
* **[attribute=value]**：特定 ARIA 属性（如 `checked`、`disabled`、`expanded`、`level` 等）。

---

## 匹配模式

### 部分匹配

省略特定属性或无障碍名称，仅验证核心结构：

```yaml
- button
- checkbox

```

### 严格匹配

默认模式下只要包含子集元素即可匹配。若要指定严格顺序与完整度，可使用 `/children` 属性控制：

* **contain**（默认）：按顺序包含指定子元素即可。
* **equal**：子元素与指定列表完全一致。
* **deep-equal**：包含嵌套子元素在内完全一致。

```yaml
- list:
  - /children: equal
  - listitem: Feature A
  - listitem: Feature B

```

## 生成快照

* **代码生成器**：在 Playwright Codegen 中使用 **Assert snapshot** 选项或直接在 **ARIA snapshot** 标签页中预览提取。
* **编程方式**：

```python
# 同步
snapshot = page.aria_snapshot()
# 异步
snapshot = await page.aria_snapshot()

```

## 常用无障碍树结构示例

* **标题与级别**：`- heading "Title" [ level=1 ]`
* **文本与多行文本**：`- text: Sample text` 或 `- paragraph: Line 1 Line 2`
* **链接**：

```yaml
- link "Read more":
  - /url: "#more-info"

```


* **状态与控件**：
* 复选框：`- checkbox [ checked ]`
* 状态按钮：`- button "Toggle" [ pressed=true ]`
* 验证输入：`- textbox "Email" [ invalid ]`
