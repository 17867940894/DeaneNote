## 简介

Playwright 可以创建指向页面 DOM 元素或页面内任何其他对象的句柄。这些句柄存在于 Playwright 进程中，而实际对象则存在于浏览器中。句柄有两种类型：

- [JSHandle](https://playwright.cn/python/docs/api/class-jshandle) 用于引用页面中的任意 JavaScript 对象
- [ElementHandle](https://playwright.cn/python/docs/api/class-elementhandle) 用于引用页面中的 DOM 元素，它具有额外的方法，允许对元素执行操作并断言其属性。

由于页面中的任何 DOM 元素同时也是一个 JavaScript 对象，因此任何 [ElementHandle](https://playwright.cn/python/docs/api/class-elementhandle) 也是一个 [JSHandle](https://playwright.cn/python/docs/api/class-jshandle)。

句柄用于对页面中的实际对象执行操作。你可以在句柄上求值、获取句柄属性、将句柄作为求值参数传递、将页面对象序列化为 JSON 等。有关这些及其他方法，请参见 [JSHandle](https://playwright.cn/python/docs/api/class-jshandle) 类 API。

### API 参考

- [JSHandle](https://playwright.cn/python/docs/api/class-jshandle)
- [ElementHandle](https://playwright.cn/python/docs/api/class-elementhandle)

以下是获取 [JSHandle](https://playwright.cn/python/docs/api/class-jshandle) 的最简单方法。

```python
js_handle = page.evaluate_handle('window')
#  Use jsHandle for evaluations.
```

## 元素句柄 (Element Handles)

> [!CAUTION]
>
> 不推荐使用 [ElementHandle](https://playwright.cn/python/docs/api/class-elementhandle)，请改用 [Locator](https://playwright.cn/python/docs/api/class-locator) 对象和 Web 优先断言（web-first assertions）。

当必须使用 [ElementHandle](https://playwright.cn/python/docs/api/class-elementhandle) 时，建议使用 [page.wait_for_selector()](https://playwright.cn/python/docs/api/class-page#page-wait-for-selector) 或 [frame.wait_for_selector()](https://playwright.cn/python/docs/api/class-frame#frame-wait-for-selector) 方法获取它。这些 API 会等待元素附加并可见。

```python
# Get the element handle
element_handle = page.wait_for_selector('#box')

# Assert bounding box for the element
bounding_box = element_handle.bounding_box()
assert bounding_box.width == 100

# Assert attribute for the element
class_names = element_handle.get_attribute('class')
assert 'highlighted' in class_names
```

## 作为参数的句柄

句柄可以传递到 [page.evaluate()](https://playwright.cn/python/docs/api/class-page#page-evaluate) 及类似方法中。以下代码片段在页面中创建一个新数组，用数据初始化它，并将指向该数组的句柄返回给 Playwright。然后它在后续的求值中使用该句柄

```python
# Create new array in page.
my_array_handle = page.evaluate_handle("""() => {
  window.myArray = [1];
  return myArray;
}""")

# Get current length of the array.
length = page.evaluate("a => a.length", my_array_handle)

# Add one more element to the array using the handle
page.evaluate("(arg) => arg.myArray.push(arg.newElement)", {
  'myArray': my_array_handle,
  'newElement': 2
})

# Release the object when it's no longer needed.
my_array_handle.dispose()
```

## 句柄生命周期

可以使用页面方法（如 [page.evaluate_handle()](https://playwright.cn/python/docs/api/class-page#page-evaluate-handle)、[page.query_selector()](https://playwright.cn/python/docs/api/class-page#page-query-selector) 或 [page.query_selector_all()](https://playwright.cn/python/docs/api/class-page#page-query-selector-all)）或其对应的 frame 方法（如 [frame.evaluate_handle()](https://playwright.cn/python/docs/api/class-frame#frame-evaluate-handle)、[frame.query_selector()](https://playwright.cn/python/docs/api/class-frame#frame-query-selector) 或 [frame.query_selector_all()](https://playwright.cn/python/docs/api/class-frame#frame-query-selector-all)）来获取句柄。一旦创建，句柄将阻止对象被[垃圾回收](https://mdn.org.cn/en-US/docs/Web/JavaScript/Memory_Management)，除非页面导航或通过 [js_handle.dispose()](https://playwright.cn/python/docs/api/class-jshandle#js-handle-dispose) 方法手动释放句柄。

## Locator 与 ElementHandle 对比

> [!CAUTION] 注意
>
> 我们仅建议在需要在静态页面上执行大量 DOM 遍历的极少数情况下使用 [ElementHandle](https://playwright.cn/python/docs/api/class-elementhandle)。对于所有的用户操作和断言，请改用定位器（locator）。

[Locator](https://playwright.cn/python/docs/api/class-locator) 和 [ElementHandle](https://playwright.cn/python/docs/api/class-elementhandle) 之间的区别在于，后者指向特定的元素，而 Locator 捕获了如何检索该元素的逻辑。

在下面的示例中，句柄指向页面上的一个特定 DOM 元素。如果该元素的文本发生变化或被 React 用于渲染一个完全不同的组件，句柄仍然指向那个陈旧的 DOM 元素。这可能会导致意外行为。

```python
handle = page.query_selector("text=Submit")
handle.hover()
handle.click()
```

使用定位器时，每次使用定位器时，都会使用选择器在页面中定位最新的 DOM 元素。因此在下面的代码片段中，底层的 DOM 元素将被定位两次。

```python
locator = page.get_by_text("Submit")
locator.hover()
locator.click()
```
