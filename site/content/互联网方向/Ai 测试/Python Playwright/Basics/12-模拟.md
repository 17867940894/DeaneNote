## 简介

使用 Playwright，您可以在任何浏览器上测试您的应用程序，还可以模拟真实设备，如手机或平板电脑。只需配置您想要模拟的设备，Playwright 就会模拟浏览器行为，例如 `"userAgent"`、`"screenSize"`、`"viewport"` 以及是否启用了 `"hasTouch"`。您还可以为所有测试或特定测试模拟 `"geolocation"`、`"locale"` 和 `"timezone"`，以及设置 `"permissions"` 以显示通知或更改 `"colorScheme"`。

## 设备

Playwright 内置了一个 [设备参数注册表](https://github.com/microsoft/playwright/blob/main/packages/playwright-core/src/server/deviceDescriptorsSource.json)，可通过 [playwright.devices](https://playwright.cn/python/docs/api/class-playwright#playwright-devices) 针对选定的桌面、平板和移动设备进行使用。它可用于模拟特定设备的浏览器行为，例如用户代理、屏幕尺寸、视口以及是否启用触控。所有测试都将使用指定的设备参数运行。

```python
from playwright.sync_api import sync_playwright, Playwright

def run(playwright: Playwright):
    iphone_13 = playwright.devices['iPhone 13']
    browser = playwright.webkit.launch(headless=False)
    context = browser.new_context(
        **iphone_13,
    )

with sync_playwright() as playwright:
    run(playwright)
```

**注意**：预配置的设备假定使用特定的平台。例如，“Desktop Chrome”将提供 Windows 特定的用户代理字符串。

如果您希望使用运行测试的平台所特有的用户代理，我们建议取消设置 user agent 属性。

```python
desktop_chrome = playwright.devices["Desktop Chrome"]
context = browser.new_context(**desktop_chrome, user_agent=None)
```

## 视口

视口已包含在设备配置中，但你可以在某些测试中使用 [page.set_viewport_size()](https://playwright.cn/python/docs/api/class-page#page-set-viewport-size) 覆盖它。

测试文件

同样适用于测试文件内部。

```python
# Create context with given viewport
context = browser.new_context(
  viewport={ 'width': 1280, 'height': 1024 }
)

# Resize viewport for individual page
page.set_viewport_size({"width": 1600, "height": 1200})

# Emulate high-DPI
context = browser.new_context(
  viewport={ 'width': 2560, 'height': 1440 },
  device_scale_factor=2,
)
```

## isMobile

是否考虑元视口标签并启用触摸事件。

```python
context = browser.new_context(
  is_mobile=False
)
```

## 区域设置与时区

模拟浏览器区域设置和时区，可以在配置中全局设置所有测试，然后针对特定测试进行覆盖。

```python
context = browser.new_context(
  locale='de-DE',
  timezone_id='Europe/Berlin',
)
```

## 权限

允许应用显示系统通知。

```python
context = browser.new_context(
  permissions=['notifications'],
)
```

允许特定域的通知。

```python
context.grant_permissions(['notifications'], origin='https://skype.com')
```

使用 [browser_context.clear_permissions()](https://playwright.cn/python/docs/api/class-browsercontext#browser-context-clear-permissions) 撤销所有权限。

```python
context.clear_permissions()
```

## 地理位置

授予`"geolocation"`权限并将地理位置设置为特定区域。

```python
context = browser.new_context(
  geolocation={"longitude": 41.890221, "latitude": 12.492348},
  permissions=["geolocation"]
)
```

![geolocation for italy on bing maps](互联网方向/Ai 测试/Python Playwright/Basics/assets/220417670-bb22d815-f5cd-47c4-8562-0b88165eac27.png)

稍后更改位置

```python
context.set_geolocation({"longitude": 48.858455, "latitude": 2.294474})
```

**注意**您只能更改上下文中所有页面的地理位置。

## 配色方案与媒体

模拟用户的 `"colorScheme"`。支持的值为 'light' 和 'dark'。你还可以使用 [page.emulate_media()](https://playwright.cn/python/docs/api/class-page#page-emulate-media) 模拟媒体类型。

```python
# Create context with dark mode
context = browser.new_context(
  color_scheme='dark' # or 'light'
)

# Create page with dark mode
page = browser.new_page(
  color_scheme='dark' # or 'light'
)

# Change color scheme for the page
page.emulate_media(color_scheme='dark')

# Change media for page
page.emulate_media(media='print')
```

## User Agent

用户代理包含在设备中，因此您很少需要更改它，但是如果您确实需要测试不同的用户代理，可以使用`userAgent`属性覆盖它。

- 同步
- 异步

```python
context = browser.new_context(
  user_agent='My user agent'
)
```

## 离线模式

模拟网络离线。

```python
context = browser.new_context(
  offline=True
)
```

## 启用 JavaScript

模拟禁用 JavaScript 的用户场景。

```python
context = browser.new_context(
  java_script_enabled=False
)
```
