## 一、AppiumBy 全家桶（对照 Selenium By）

Appium 复用 Selenium 的 `By`，但**新增了移动端专属策略**。导入方式：

```python
from appium.webdriver.common.appiumby import AppiumBy
```

| AppiumBy 策略 | 对应 Web By | 移动端含义 | 稳定性 | 速度 |
| --- | --- | --- | --- | --- |
| `AppiumBy.ID` | `By.ID` | Android `resource-id`（如 `com.tal.kaoyan:id/xxx`） | ⭐⭐⭐⭐⭐ | 快 | 
| `AppiumBy.ACCESSIBILITY_ID` | — | `content-desc`（无障碍标识） | ⭐⭐⭐⭐⭐ | 快 |
| `AppiumBy.XPATH` | `By.XPATH` | XML 路径，功能最强但最慢 | ⭐⭐ | 慢 |
| `AppiumBy.CLASS_NAME` | `By.CLASS_NAME` | 控件类名（`android.widget.EditText`） | ⭐⭐（易重复） | 中 |
| `AppiumBy.ANDROID_UIAUTOMATOR` | — | UiAutomator 原生选择器（文本/描述/滚动） | ⭐⭐⭐⭐ | 快 |
| `AppiumBy.IOS_PREDICATE` | — | iOS 谓词表达式 | iOS 专用 | 快 |
| `AppiumBy.ANDROID_VIEWTAG` | — | `view.setTag()` 设置的标签 | ⭐⭐⭐⭐ | 快 |

> [!tip] 定位优先级（移动端黄金法则）
> **ID > ACCESSIBILITY_ID > ANDROID_UIAUTOMATOR > XPath**
> 和 Web 端"ID > CSS > XPath"完全一致。XPath 在移动端最慢且最易因布局变动失效，**能不用就不用**。

## 二、Appium Inspector（可视化抓取，必装）

Appium Inspector 是官方元素抓取工具，相当于移动端的 F12。

### 2.1 安装与连接

1. 下载：<https://github.com/appium/appium-inspector/releases>
2. 确保 Appium Server 已运行（`appium --relaxed-security`）
3. 打开 Inspector，填写 **Remote Host** `127.0.0.1`、**Port** `4723`、**Path** `/`
4. 在 `capabilities` 区填入（JSON 形式，与你 `config.yaml` 的 capabilities 一致）：

```json
{
  "platformName": "Android",
  "appium:automationName": "UiAutomator2",
  "appium:deviceName": "MuMu",
  "appium:udid": "127.0.0.1:7555",
  "appium:appPackage": "com.tal.kaoyan",
  "appium:appActivity": "com.kaoyan.kylogin.ui.login.LoginKActivity",
  "appium:noReset": true
}
```

> [!note] `appium:` 前缀
> Inspector / capabilities 里，Appium 专属项要加 `appium:` 前缀（如 `appium:udid`）。代码里用 `UiAutomator2Options()` 设属性时则不用前缀（见 [[01-环境搭建与工程初始化]] 的 `driver_factory.py`）。

5. 点 **Start Session** → 模拟器会拉起考研帮，左侧显示控件树，点元素即可看到 `resource-id` / `content-desc` / `xpath`。

### 2.2 用 Inspector 抓考研帮登录页

| 控件 | 抓取到的属性（示例，以你机器为准） | 推荐定位方式 |
| --- | --- | --- |
| 手机号输入框 | `resource-id = com.tal.kaoyan:id/login_account_edittext` | `AppiumBy.ID` |
| 密码输入框 | `resource-id = com.tal.kaoyan:id/login_password_edittext` | `AppiumBy.ID` |
| 登录按钮 | `text = 登录` / `resource-id = ...login_login_btn` | `AppiumBy.ID` 或 `ACCESSIBILITY_ID` |
| "同意协议"勾选框 | `resource-id = ...login_agreement_checkbox` | `AppiumBy.ID` |

> [!warning] 版本差异
> 考研帮不同版本 resource-id 会变。**以你本地 Inspector 抓取结果为准**，本表仅为示例。

## 三、各策略代码示例

```python
from appium.webdriver.common.appiumby import AppiumBy
from pages.base_page import BasePage


class LoginPage(BasePage):
    # ===== 定位器集中声明（UI 变了只改这里）=====
    phone_input   = (AppiumBy.ID, "com.tal.kaoyan:id/login_account_edittext")
    pwd_input     = (AppiumBy.ID, "com.tal.kaoyan:id/login_password_edittext")
    login_btn     = (AppiumBy.ID, "com.tal.kaoyan:id/login_login_btn")
    agreement_cb  = (AppiumBy.ID, "com.tal.kaoyan:id/login_agreement_checkbox")

    # ===== 备选：AccessibilityId（content-desc）=====
    login_btn_a11y = (AppiumBy.ACCESSIBILITY_ID, "登录")

    # ===== 备选：UiAutomator 文本定位（不依赖 id）=====
    login_btn_uia  = (AppiumBy.ANDROID_UIAUTOMATOR, 'new UiSelector().text("登录")')

    # ===== 备选：XPath（最慢，慎用）=====
    login_btn_xpath = (AppiumBy.XPATH, '//android.widget.Button[@text="登录"]')

    def fill_phone(self, phone):
        self.type(self.phone_input, phone)
        return self

    def fill_pwd(self, pwd):
        self.type(self.pwd_input, pwd)
        return self

    def tap_login(self):
        self.click(self.login_btn)
        return self
```

### 3.1 iOS 差异化定位（若你以后测 iOS）

```python
# iOS 用 Predicate 字符串
ios_login = (AppiumBy.IOS_PREDICATE, "label == '登录' AND visible == 1")
# 或 className + name
ios_login2 = (AppiumBy.ACCESSIBILITY_ID, "loginButton")
```

## 五、常见报错与排查点

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `NoSuchElementException` | 元素未出现 / 定位表达式错 | ① 用 Inspector 核对真实 id；② 是否跨了 context（H5 要先切 WebView，见 [[04-常用操作API]]）；③ 加显式等待（[[03-等待机制]]） |
| `InvalidSelectorException`（XPath） | XPath 语法错 / 用了 `//*[text()=]` 等不支持写法 | 移动端 XPath 用 `//android.widget.TextView[@text='x']`；或改用 UiAutomator |
| `element is not visible` 但能找到 | 元素在屏幕外 / 被遮挡 | 先滚动到视野内（`UiScrollable`，见 [[04-常用操作API]]）再操作 |
| 定位到多个元素报错 | `CLASS_NAME`/`XPATH` 匹配到多个 | 改用 `find_elements` 取索引，或换成更精确的 ID |
| Inspector 连不上 | Server 没开 / `appium:` 前缀错 | 确认 Server 运行；capabilities 加 `appium:` 前缀 |
| 点击到错误位置 | 控件重叠 / 动画未结束 | 用显式等待 `element_to_be_clickable` 后再点 |

> [!tip] 调试定位的小技巧
> 在用例里临时打印页面源码，对照 Inspector：
> ```python
> print(driver.page_source[:2000])   # 打印当前页面 XML 结构
> ```
