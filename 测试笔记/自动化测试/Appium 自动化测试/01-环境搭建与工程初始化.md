## 一、Appium 是什么（和你已知的 Selenium 同构）

Appium 是**移动端**的"Selenium"：它把 WebDriver 协议扩展到 iOS/Android，让你用同一套 Client API 驱动真机/模拟器上的 App。

```text
你的 Python 测试代码
   │  (WebDriver 协议 / HTTP JSON Wire)
   ▼
Appium Server  (Node.js, 默认 127.0.0.1:4723)
   │  根据 automationName 转发给对应驱动
   ▼
UiAutomator2 Driver (Android)  ──►  被测 App (com.tal.kaoyan)
   (或 XCUITest Driver for iOS)
```

**关键认知**：Appium Server 只是个"翻译中转站"。它自己不动 App，而是把命令转给底层驱动（Android 用 UiAutomator2，iOS 用 XCUITest）。这点和 Selenium 的 `ChromeDriver` 角色一致——你之前写 `webdriver.Chrome()`，现在写 `webdriver.Remote(server, options)`，本质一样。

> [!tip] 你已具备的迁移基础
> - `find_element` / `WebDriverWait` / `expected_conditions` **完全通用**（Appium 复用 Selenium 4 的 API）
> - pytest、`conftest.py`、`parametrize`、PO 模式 **完全通用**
> - 唯一新增概念：**Capabilities**（告诉 Appium 连哪个设备、开哪个 App）和**移动端专属定位/手势**

### 2.1 安装 Appium 2.x 与驱动

```bash
# 1) 装 Appium 2（需要 Node 18+）
npm install -g appium@2

# 2) 验证
appium -v            # 应输出 2.x.x

# 3) 安装 Android 驱动（关键！Appium 2 默认不含任何驱动）
appium driver install uiautomator2

# 4) 确认驱动已安装
```

> ```bash

> adb devices            # 看到 127.0.0.1:7555  device
> ```

### 3.3 配置读取 `utils/config_loader.py`

```python
import os
import yaml

def load_config(path: str = None) -> dict:
    """读取 config/config.yaml，返回 dict。"""
    if path is None:
        path = os.path.join(os.path.dirname(__file__), "..", "config", "config.yaml")
    with open(path, encoding="utf-8") as f:
        return yaml.safe_load(f)
```

### 3.4 Driver 工厂 `utils/driver_factory.py`

Capabilities 只在这一处出现，全项目统一：

```python
from appium import webdriver
from appium.options.android import UiAutomator2Options
from utils.config_loader import load_config


def create_driver() -> webdriver.Remote:
    cfg = load_config()
    caps = cfg["capabilities"]

    options = UiAutomator2Options()
    options.platform_name = caps["platformName"]
    options.automation_name = caps["automationName"]
    options.device_name = caps["deviceName"]
    options.udid = caps["udid"]
    options.app_package = caps["appPackage"]
    options.app_activity = caps["appActivity"]
    options.no_reset = caps.get("noReset", True)
    options.new_command_timeout = cfg["appium"].get("newCommandTimeout", 300)

    server = cfg["appium"]["server_url"]
    driver = webdriver.Remote(server, options=options)
    return driver
```

### 3.5 等待封装 `utils/wait_helper.py`

移动端比 Web 更依赖显式等待（页面渲染、动画、网络都更慢）：

```python
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC


class WaitHelper:
    def __init__(self, driver, timeout: int = 10):
        self.driver = driver
        self.timeout = timeout

    def element_visible(self, locator, timeout=None):
        return WebDriverWait(self.driver, timeout or self.timeout).until(
            EC.visibility_of_element_located(locator)
        )

    def element_clickable(self, locator, timeout=None):
        return WebDriverWait(self.driver, timeout or self.timeout).until(
            EC.element_to_be_clickable(locator)
        )

    def is_element_visible(self, locator, timeout: int = 3) -> bool:
        try:
            self.element_visible(locator, timeout)
            return True
        except Exception:
            return False
```

### 3.6 页面基类 `pages/base_page.py`（先放最小版）

```python
from utils.wait_helper import WaitHelper
from appium.webdriver.common.appiumby import AppiumBy


class BasePage:
    def __init__(self, driver):
        self.driver = driver
        self.wait = WaitHelper(driver, timeout=10)

    def find(self, locator, timeout=None):
        return self.wait.element_visible(locator, timeout)

    def click(self, locator, timeout=None):
        self.wait.element_clickable(locator, timeout).click()
        return self

    def type(self, locator, text, timeout=None):
        el = self.wait.element_visible(locator, timeout)
        el.clear()
        el.send_keys(text)
        return self

    def is_element_visible(self, locator, timeout=3) -> bool:
        return self.wait.is_element_visible(locator, timeout)
```

### 3.7 pytest 配置 `pytest.ini` + 夹具 `conftest.py`

```ini
[pytest]
testpaths = testcases
python_files = test_*.py
addopts = -v --alluredir=reports/allure --html=reports/report.html --self-contained-html
```

```python
import os
import pytest
from utils.driver_factory import create_driver
from utils.screenshot import screenshot_on_failure   # 见 07 章，先占位可删


@pytest.fixture(scope="session")
def driver():
    drv = create_driver()
    drv.implicitly_wait(5)
    yield drv
    drv.quit()


@pytest.hookimpl(hookwrapper=True)
def pytest_runtest_makereport(item):
    """用例失败时自动截图（配合 07 章的 screenshot 工具）。"""
    outcome = yield
    report = outcome.get_result()
    if report.when == "call" and report.failed:
        driver = item.funcargs.get("driver")
        if driver:
            name = f"{item.name}_{int(__import__('time').time())}"
            screenshot_on_failure(driver, name)
```

### 3.8 第一个用例 `testcases/test_first_launch.py`

```python
import pytest
from appium.webdriver.common.appiumby import AppiumBy
from pages.base_page import BasePage


class TestFirstLaunch:
    def test_app_launch_and_login_page_visible(self, driver):
        """启动考研帮，判定登录页手机号输入框可见。"""
        # 考研帮登录页"手机号"输入框的 resource-id（示例，需用 Inspector 核对）
        phone_input = (AppiumBy.ID, "com.tal.kaoyan:id/login_account_edittext")

        base = BasePage(driver)
        assert base.is_element_visible(phone_input, timeout=15), "登录页未加载 / 元素定位错误"
        print("✅ 考研帮启动成功，登录页可见")
```

> [!warning] 关于示例 resource-id
> 上面 `com.tal.kaoyan:id/login_account_edittext` 是**示意 ID**。不同版本考研帮的 resource-id 会变。请按 [[02-元素定位策略]] 用 **Appium Inspector** 获取你当前版本的真实 ID，再回填。

## 五、常见报错与排查点

| 报错 / 现象 | 可能原因 | 排查 / 解决 |
| --- | --- | --- |
| `ConnectionRefusedError: 127.0.0.1:4723` | Appium Server 没起 / 端口不对 | 确认 `appium --relaxed-security` 已运行；`config.yaml` 的 `server_url` 端口一致 |
| `An unknown server-side error occurred... Could not find a driver` | 没装 UiAutomator2 驱动 | `appium driver install uiautomator2`；`appium driver list` 确认 installed |
| `deviceName`/`udid` 连不上，报 `device not found` | 模拟器未连 / 端口错 | `adb connect 127.0.0.1:7555`；`adb devices` 确认；`udid` 填 `127.0.0.1:7555` |
| `Activity used to start app doesn't exist` | `appActivity` 写错 | 用 `adb shell dumpsys window \| grep mCurrentFocus` 取真实 Activity |
| `AppiumBy` 导入报错 `cannot import name 'AppiumBy'` | 客户端版本 < 2.0 | 升级 `pip install -U Appium-Python-Client`（需 3.x） |
| 用例一直 `NoSuchElementException` | 元素未加载 / ID 不对 | ① 确认用 Inspector 拿的真实 ID；② 加大 `is_element_visible` 的 timeout；③ 见 [[03-等待机制]] |
| `WebDriverException: socket hang up` | Appium Server 崩溃 / 驱动异常 | 看 Appium Server 终端日志；重启 Server；检查模拟器是否掉线 |
| 每次运行都重装/清登录态 | `noReset` 没设 | `config.yaml` 设 `noReset: true` |

> [!tip] 一条命令自检
> ```bash
> adb devices && appium driver list && echo "Server 状态:" && curl -s http://127.0.0.1:4723/status
> ```
> 三项都正常，才具备跑用例的条件。
