# 4.6 其他制作镜像的方式

> **来源**：Docker 入门教程


## 一、从 rootfs 压缩包导入（docker import）

### 1.1 命令格式

```bash
docker import [选项] <文件>|<URL>|- [<仓库名>[:<标签>]]
```

压缩包可以是本地文件、远程 Web 文件，甚至是从标准输入中得到。压缩包将会在镜像 `/` 目录展开，并直接作为镜像第一层提交。

### 1.2 示例：导入 OpenVZ Ubuntu 模板

```bash
$ docker import \
    http://download.openvz.org/template/precreated/ubuntu-16.04-x86_64.tar.gz \
    openvz/ubuntu:16.04

Downloading from http://download.openvz.org/template/precreated/ubuntu-16.04-x86_64.tar.gz
sha256:412b8fc3e3f786dca0197834a698932b9c51b69bd8cf49e100c35d38c9879213
```

> **版本提示**：示例中 `ubuntu-16.04` 仅用于演示用法。实际生产环境应选择仍在安全维护期内的发行版（如 Ubuntu 22.04 LTS 或 24.04 LTS），并按团队的基础镜像更新策略定期重建。

### 1.3 查看导入的镜像

```bash
$ docker image ls openvz/ubuntu
REPOSITORY          TAG                 IMAGE ID            CREATED             SIZE
openvz/ubuntu       16.04               412b8fc3e3f7        55 seconds ago      505MB
```

### 1.4 查看镜像历史

```bash
$ docker history openvz/ubuntu:16.04
IMAGE               CREATED              CREATED BY          SIZE                COMMENT
f477a6e18e98        About a minute ago                       214.9 MB            Imported from http://download.openvz.org/template/precreated/ubuntu-16.04-x86_64.tar.gz
```


## 二、镜像的导出和导入（docker save / docker load）

> **注意**：`docker save` 和 `docker load` 是在没有 Docker Registry 时的做法，**现在已经不推荐**。镜像迁移应直接使用 Docker Registry（Docker Hub 或内网私有 Registry）。

### 2.1 保存镜像（docker save）

使用 `docker save` 命令可以将镜像保存为归档文件。

```bash
$ docker image ls alpine
REPOSITORY          TAG                 IMAGE ID            CREATED             SIZE
alpine              latest              baa5d63471ea        5 weeks ago         4.803 MB
```

```bash
# 保存为 tar 文件
$ docker save alpine -o filename
$ file filename
filename: POSIX tar archive
```

> **版本提示**：`alpine:latest` 为最新版本的 Alpine Linux。如果需要特定版本号（如 `alpine:3.20`），应明确指定以确保可重现性。
>
> ⚠️ **注意**：如果同名文件已存在，会被**直接覆盖（无警告）**。

```bash
# 保存并压缩为 gzip
$ docker save alpine | gzip > alpine-latest.tar.gz
```

### 2.2 加载镜像（docker load）

将保存的镜像文件复制到另一台机器后，可以用以下命令加载：

```bash
$ docker load -i alpine-latest.tar.gz
Loaded image: alpine:latest
```

### 2.3 高级用法：跨机器迁移（带进度条）

结合 `docker save`、`ssh` 和 `pv`，可以一条命令完成跨机器迁移并显示进度：

```bash
docker save <镜像名> | bzip2 | pv | ssh <用户名>@<主机名> 'cat | docker load'
```


## 三、两种方式对比

| 方式 | 命令 | 适用场景 | 推荐度 |
|---|---|---|---|
| **从 rootfs 导入** | `docker import` | 从非 Docker 来源的根文件系统创建镜像 | 特殊场景 |
| **导出/导入镜像** | `docker save` / `docker load` | 无 Registry 环境下的镜像迁移 | ❌ 不推荐 |
| **使用 Registry** | `docker push` / `docker pull` | 镜像分发和迁移 | ✅ 推荐 |


## 四、docker save 与 docker export 的区别

| 命令 | 操作对象 | 内容 |
|---|---|---|
| `docker save` | **镜像** | 保存镜像的所有层和元数据 |
| `docker export` | **容器** | 导出容器的文件系统快照（不包含层历史和元数据） |

> 💡 日常使用应优先通过 **Docker Registry**（如 Docker Hub、Harbor 等）进行镜像分发，而非手动传输文件。
