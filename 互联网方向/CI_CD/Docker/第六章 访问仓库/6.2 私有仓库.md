# 6.2 私有仓库（Docker Registry）

> **来源**：Docker 入门教程


## 一、概述

有时使用 Docker Hub 这样的公共仓库可能不方便，用户可以创建一个本地仓库供私人使用。

[Docker Registry](https://distribution.github.io/distribution/) 是官方提供的工具，可以用于构建私有的镜像仓库。

> **版本说明**：本文示例沿用 Distribution v2.x 兼容路径；新生产部署应评估 Distribution 3.x，并核对配置路径、迁移说明和生态兼容性。旧版本 Registry 1.x 已停止维护，不建议使用。


## 二、安装运行 Docker Registry

### 2.1 容器运行

使用官方 `registry` 镜像快速部署：

```bash
$ docker run -d -p 5000:5000 --restart=always --name registry registry:2
```

默认情况下，仓库会被创建在容器的 `/var/lib/registry` 目录下。可以通过 `-v` 参数将镜像文件存放在本地的指定路径：

```bash
$ docker run -d \
    -p 5000:5000 \
    -v /opt/data/registry:/var/lib/registry \
    registry:2
```


## 三、在私有仓库上传、搜索、下载镜像

### 3.1 标记镜像

使用 `docker tag` 将本地镜像标记为私有仓库地址：

```bash
# 查看本地镜像
$ docker image ls
REPOSITORY                        TAG                 IMAGE ID            CREATED             VIRTUAL SIZE
ubuntu                            latest              ba5877dc9bec        6 weeks ago         192.7 MB

# 标记镜像（格式：docker tag IMAGE[:TAG] [REGISTRY_HOST[:REGISTRY_PORT]/]REPOSITORY[:TAG]）
$ docker tag ubuntu:latest 127.0.0.1:5000/ubuntu:latest

# 再次查看，新增了一个标记
$ docker image ls
REPOSITORY                        TAG                 IMAGE ID            CREATED             VIRTUAL SIZE
ubuntu                            latest              ba5877dc9bec        6 weeks ago         192.7 MB
127.0.0.1:5000/ubuntu             latest              ba5877dc9bec        6 weeks ago         192.7 MB
```

### 3.2 推送镜像


### 3.3 查看仓库中的镜像

使用 `curl` 查看：

```bash
$ curl 127.0.0.1:5000/v2/_catalog
{"repositories":["ubuntu"]}
```

### 3.4 下载镜像

```bash
# 先删除已有镜像
$ docker image rm 127.0.0.1:5000/ubuntu:latest

# 从私有仓库拉取
```

## 四、配置非 HTTPS 仓库地址

如果你想让本网段的其他主机也能把镜像推送到私有仓库（如 `192.168.199.100:5000`），会发现无法成功推送。这是因为 Docker **默认不允许非 HTTPS 方式推送镜像**。

### 4.1 Linux 系统配置

对于使用 `systemd` 的系统，在 `/etc/docker/daemon.json` 中写入如下内容（如果文件不存在请新建）：

```json
{
  "registry-mirrors": [
    "https://docker.your-mirror.example.com"
  ],
  "insecure-registries": [
    "192.168.199.100:5000"
  ]
}
```

> **注意**：
> - 该文件必须符合 JSON 规范，否则 Docker 将不能启动
> - 镜像加速器地址请替换为实际可用的源

### 4.2 Docker Desktop（Windows / Mac）

在 Docker Desktop 设置中的 **Docker Engine** 进行编辑，增加相同配置即可。


## 五、命令速查

| 命令 | 说明 |
|---|---|
| `docker run -d -p 5000:5000 registry:2` | 启动私有仓库容器 |
| `docker tag <镜像> <仓库地址>/<镜像名>:<标签>` | 为镜像打标签 |
| `docker push <仓库地址>/<镜像名>:<标签>` | 推送镜像到私有仓库 |
| `docker pull <仓库地址>/<镜像名>:<标签>` | 从私有仓库拉取镜像 |
| `curl <仓库地址>/v2/_catalog` | 查看仓库中的镜像列表 |
