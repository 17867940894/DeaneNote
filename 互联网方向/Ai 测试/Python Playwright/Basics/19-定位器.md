## 简介

[Locator](https://playwright.cn/python/docs/api/class-locator)（定位器）是 Playwright 自动等待和重试机制的核心。简而言之，定位器代表了一种在任何时刻查找页面上元素的方法。

### 快速指南

以下是推荐的内置定位器。

- [page.get_by_role()](https://playwright.cn/python/docs/locators#locate-by-role)：根据显式和隐式可访问性属性进行定位。
- [page.get_by_text()](https://playwright.cn/python/docs/locators#locate-by-text)：根据文本内容进行定位。
- [page.get_by_label()](https://playwright.cn/python/docs/locators#locate-by-label)：通过关联标签的文本定位表单控件。
- [page.get_by_placeholder()](https://playwright.cn/python/docs/locators#locate-by-placeholder)：通过占位符定位输入框。
- [page.get_by_alt_text()](https://playwright.cn/python/docs/locators#locate-by-alt-text)：通过文本替代项定位元素（通常是图像）。
- [page.get_by_title()](https://playwright.cn/python/docs/locators#locate-by-title)：通过标题属性定位元素。
- [page.get_by_test_id()](https://playwright.cn/python/docs/locators#locate-by-test-id)：根据元素的 `data-testid` 属性定位元素（可配置其他属性）。

```python
page.get_by_label("User Name").fill("John")

page.get_by_label("Password").fill("secret-password")

page.get_by_role("button", name="Sign in").click()

expect(page.get_by_text("Welcome, John!")).to_be_visible()
```

## 定位元素

Playwright 内置了多种定位器。为了使测试更具弹性，我们建议优先使用面向用户的属性和显式契约，例如 [page.get_by_role()](https://playwright.cn/python/docs/api/class-page#page-get-by-role)。

。

```html
<button>Sign in</button>
```

通过其 `button` 角色和名称“登录”定位元素。

```python
page.get_by_role("button", name="Sign in").click()
```

> [!caution]
>
> 使用 [代码生成器](https://playwright.cn/python/docs/codegen) 生成定位器，然后根据需要进行编辑。

每次对定位器执行操作时，都会在页面上定位一个最新的 DOM 元素。在下面的代码片段中，底层的 DOM 元素将被定位两次，每次操作前定位一次。这意味着如果 DOM 在调用之间因重新渲染而发生变化，将使用与定位器对应的 **新** 元素。

```python
locator = page.get_by_role("button", name="Sign in")

locator.hover()
locator.click()
```

请注意，所有用于创建定位器的方法（例如 [page.get_by_label()](https://playwright.cn/python/docs/api/class-page#page-get-by-label)）同样适用于 [Locator](https://playwright.cn/python/docs/api/class-locator) 和 [FrameLocator](https://playwright.cn/python/docs/api/class-framelocator) 类，因此你可以链式调用它们以逐步缩小定位范围。

```python
locator = page.frame_locator("my-frame").get_by_role("button", name="Sign in")

locator.click()
```

### 通过角色定位

[page.get_by_role()](https://playwright.cn/python/docs/api/class-page#page-get-by-role) 定位器反映了用户和辅助技术如何感知页面，例如某个元素是按钮还是复选框。通过角色定位时，通常还应传入可访问名称，以便定位器精确指向目标元素。

。

```html
<h3>Sign up</h3>
<label> <input type="checkbox" /> Subscribe </label>
<br />
<button>Submit</button>
```

可以按其隐式角色定位每个元素

```py
expect(page.get_by_role("heading", name="Sign up")).to_be_visible()

page.get_by_role("checkbox", name="Subscribe").check()

page.get_by_role("button", name=re.compile("submit", re.IGNORECASE)).click()
```

角色定位器包括 [按钮、复选框、标题、链接、列表、表格等](https://www.w3.org/TR/html-aria/#docconformance)，并遵循 W3C 关于 [ARIA 角色](https://www.w3.org/TR/wai-aria-1.2/#roles)、[ARIA 属性](https://www.w3.org/TR/wai-aria-1.2/#aria-attributes) 和 [可访问名称](https://w3c.github.io/accname/#dfn-accessible-name) 的规范。请注意，许多 HTML 元素（如 `<button>`）具有角色定位器可识别的 [隐式定义角色](https://w3c.github.io/html-aam/#html-element-role-mappings)。

请注意，角色定位器 **不替代** 辅助功能审计和符合性测试，而是提供有关 ARIA 指南的早期反馈。

> [!caution]
>
> 何时使用角色定位器
>
> 我们建议优先使用角色定位器来定位元素，因为这是最接近用户和辅助技术感知页面的方式。

### 通过标签定位

大多数表单控件通常都有专用的标签，可以方便地用于与表单交互。在这种情况下，你可以使用 [page.get_by_label()](https://playwright.cn/python/docs/api/class-page#page-get-by-label) 通过其关联的标签定位控件。

。

```html
<label>Password <input type="password" /></label>
```

可以通过标签文本定位输入框后填充它

```python
page.get_by_label("Password").fill("secret")
```

> [!caution]
>
> 何时使用标签定位器
>
> 在定位表单字段时使用此定位器。

### 通过占位符定位

输入框可能具有占位符属性，以提示用户应输入什么值。你可以使用 [page.get_by_placeholder()](https://playwright.cn/python/docs/api/class-page#page-get-by-placeholder) 定位此类输入框。

。

```html
<input type="email" placeholder="name@example.com" />
```

可以按占位符文本定位输入框后填充它

```python
page.get_by_placeholder("name@example.com").fill("playwright@microsoft.com")
```

> [!caution]
>
> 何时使用占位符定位器
>
> 当定位没有标签但有占位符文本的表单元素时，使用此定位器。

### 通过文本定位

通过包含的文本查找元素。使用 [page.get_by_text()](https://playwright.cn/python/docs/api/class-page#page-get-by-text) 时，你可以通过子字符串、精确字符串或正则表达式进行匹配。

。

```html
<span>Welcome, John</span>
```

您可以按元素包含的文本定位它

```python
expect(page.get_by_text("Welcome, John")).to_be_visible()
```

设置精确匹配

```python
expect(page.get_by_text("Welcome, John", exact=True)).to_be_visible()
```

使用正则表达式匹配

```python
expect(page.get_by_text(re.compile("welcome, john", re.IGNORECASE))).to_be_visible()
```

> [!caution]
>
> 按文本匹配始终会规范化空格，即使是精确匹配也是如此。例如，它会将多个空格转换为一个空格，将换行符转换为空格，并忽略前导和尾随空格。
>
> **何时使用文本定位器**
>
> 我们建议使用文本定位器查找非交互式元素，如 `div`、`span`、`p` 等。对于交互式元素（如 `button`、`a`、`input` 等），请使用 [角色定位器](https://playwright.cn/python/docs/locators#locate-by-role)。

您还可以通过 [文本过滤](https://playwright.cn/python/docs/locators#filter-by-text)，这在尝试查找列表中的特定项目时非常有用。

### 通过替代文本定位

所有图像都应该有一个描述图像的 `alt` 属性。你可以使用 [page.get_by_alt_text()](https://playwright.cn/python/docs/api/class-page#page-get-by-alt-text) 根据文本替代项定位图像。

。

```html
<img alt="playwright logo" src="/img/playwright-logo.svg" width="100" />
```

您可以通过文本替代内容定位图像后点击它

```python
page.get_by_alt_text("playwright logo").click()
```

> [!caution]
>
> 何时使用 alt 定位器
>
> 当您的元素支持 alt 文本时（如 `img` 和 `area` 元素），请使用此定位器。

### 通过标题定位

使用 [page.get_by_title()](https://playwright.cn/python/docs/api/class-page#page-get-by-title) 定位具有匹配 title 属性的元素。

。

```html
<span title="Issues count">25 issues</span>
```

您可以通过 title 文本定位它后检查问题数量

```python
expect(page.get_by_title("Issues count")).to_have_text("25 issues")
```

> [!caution]
>
> 何时使用 title 定位器
>
> 当您的元素具有 `title` 属性时，使用此定位器。

### 通过测试 ID 定位

使用测试 ID 进行测试是最具弹性的测试方式，因为即使你的文本或属性角色发生变化，测试仍然能通过。QA 和开发人员应当定义显式的测试 ID，并使用 [page.get_by_test_id()](https://playwright.cn/python/docs/api/class-page#page-get-by-test-id) 查询它们。但是，通过测试 ID 进行测试并不是面向用户的。如果你关注角色或文本值，请考虑使用面向用户的定位器，例如 [role](https://playwright.cn/python/docs/locators#locate-by-role) 和 [text 定位器](https://playwright.cn/python/docs/locators#locate-by-text)。

。

```html
<button data-testid="directions">Itinéraire</button>
```

您可以按其测试 ID 定位元素

```python
page.get_by_test_id("directions").click()
```

> [!caution]
>
> 何时使用 testid 定位器
>
> 当您决定使用测试 ID 方法论，或者无法通过 [角色](https://playwright.cn/python/docs/locators#locate-by-role) 或 [文本](https://playwright.cn/python/docs/locators#locate-by-text) 定位时，也可以使用测试 ID。

#### 设置自定义测试 ID 属性

默认情况下，[page.get_by_test_id()](https://playwright.cn/python/docs/api/class-page#page-get-by-test-id) 将根据 `data-testid` 属性定位元素，但你可以在测试配置中进行配置，或者通过调用 [selectors.set_test_id_attribute()](https://playwright.cn/python/docs/api/class-selectors#selectors-set-test-id-attribute) 来进行配置。

设置测试 ID 以便为您的测试使用自定义数据属性。

```python
playwright.selectors.set_test_id_attribute("data-pw")
```

在您的 HTML 中，您现在可以使用 `data-pw` 作为测试 ID，而不是默认的 `data-testid`。

```html
<button data-pw="directions">Itinéraire</button>
```

然后像通常一样定位元素

```python
page.get_by_test_id("directions").click()
```

### 通过 CSS 或 XPath 定位

如果你绝对必须使用 CSS 或 XPath 定位器，你可以使用 [page.locator()](https://playwright.cn/python/docs/api/class-page#page-locator) 创建一个定位器，它接收一个选择器来描述如何在页面中查找元素。Playwright 支持 CSS 和 XPath 选择器，如果你省略了 `css=` 或 `xpath=` 前缀，它会自动检测。

```python
page.locator("css=button").click()
page.locator("xpath=//button").click()

page.locator("button").click()
page.locator("//button").click()
```

XPath 和 CSS 选择器可能与 DOM 结构或实现绑定。当 DOM 结构发生变化时，这些选择器可能会失效。下面冗长的 CSS 或 XPath 链是导致测试不稳定的 **不良实践** 示例

```python
page.locator(
    "#tsf > div:nth-child(2) > div.A8SBwf > div.RNNXgb > div > div.a4bIc > input"
).click()

page.locator('//*[@id="tsf"]/div[2]/div[1]/div[1]/div/div[2]/input').click()
```

> [!caution]
>
> 何时使用此方法
>
> 不推荐使用 CSS 和 XPath，因为 DOM 经常会发生变化，导致测试不稳定。相反，尝试构建一个更贴近用户感知页面的定位器，例如 [角色定位器](https://playwright.cn/python/docs/locators#locate-by-role)，或使用测试 ID [定义明确的测试契约](https://playwright.cn/python/docs/locators#locate-by-test-id)。

## 在 Shadow DOM 中定位

Playwright 中的所有定位器 **默认情况下** 都适用于 Shadow DOM 中的元素。例外情况是

- 按 XPath 定位不会穿透 Shadow Roots。
- 不支持 [Closed 模式的 Shadow Roots](https://mdn.org.cn/en-US/docs/Web/API/Element/attachShadow#parameters)。

考虑以下带有自定义 Web 组件的示例

```html
<x-details role="button" aria-expanded="true" aria-controls="inner-details">
  <div>Title</div>
  #shadow-root
  <div id="inner-details">Details</div>
</x-details>
```

您可以像 Shadow Root 不存在一样进行定位。

点击 `<div>Details</div>`

```python
page.get_by_text("Details").click()
```

```html
<x-details role="button" aria-expanded="true" aria-controls="inner-details">
  <div>Title</div>
  #shadow-root
  <div id="inner-details">Details</div>
</x-details>
```

点击 `<x-details>`

```python
page.locator("x-details", has_text="Details").click()
```

```html
<x-details role="button" aria-expanded="true" aria-controls="inner-details">
  <div>Title</div>
  #shadow-root
  <div id="inner-details">Details</div>
</x-details>
```

确保 `<x-details>` 包含文本“详细信息”

```python
expect(page.locator("x-details")).to_contain_text("Details")
```

## 过滤定位器

考虑以下 DOM 结构，我们想点击第二个产品卡片的购买按钮。我们有几种选择来过滤定位器以获得正确的定位器。

```html
<ul>
  <li>
    <h3>Product 1</h3>
    <button>Add to cart</button>
  </li>
  <li>
    <h3>Product 2</h3>
    <button>Add to cart</button>
  </li>
</ul>
```

### 通过文本过滤

可以使用 [locator.filter()](https://playwright.cn/python/docs/api/class-locator#locator-filter) 方法按文本过滤定位器。它将在元素内部的某个地方（可能在后代元素中）不区分大小写地搜索特定的字符串。你也可以传入正则表达式。

```python
page.get_by_role("listitem").filter(has_text="Product 2").get_by_role(
    "button", name="Add to cart"
).click()
```

使用正则表达式

```python
page.get_by_role("listitem").filter(has_text=re.compile("Product 2")).get_by_role(
    "button", name="Add to cart"
).click()
```

### 通过不包含文本进行过滤

或者，按 **不包含** 文本进行过滤

```python
# 5 in-stock items
expect(page.get_by_role("listitem").filter(has_not_text="Out of stock")).to_have_count(5)
```

### 通过子元素/后代元素过滤

定位器支持一个选项，用于仅选择包含或不包含匹配另一个定位器的后代元素的元素。因此，你可以通过任何其他定位器进行过滤，例如 [locator.get_by_role()](https://playwright.cn/python/docs/api/class-locator#locator-get-by-role)、[locator.get_by_test_id()](https://playwright.cn/python/docs/api/class-locator#locator-get-by-test-id)、[locator.get_by_text()](https://playwright.cn/python/docs/api/class-locator#locator-get-by-text) 等。

```html
<ul>
  <li>
    <h3>Product 1</h3>
    <button>Add to cart</button>
  </li>
  <li>
    <h3>Product 2</h3>
    <button>Add to cart</button>
  </li>
</ul>
```

```python
page.get_by_role("listitem").filter(
    has=page.get_by_role("heading", name="Product 2")
).get_by_role("button", name="Add to cart").click()
```

我们还可以断言产品卡片以确保只有一个

```python
expect(
    page.get_by_role("listitem").filter(
        has=page.get_by_role("heading", name="Product 2")
    )
).to_have_count(1)
```

过滤定位器 **必须相对于** 原始定位器，并且从原始定位器匹配项开始查询，而不是从文档根开始。因此，以下代码将无效，因为过滤定位器从 `<li>` 列表项 **外部** 的 `<ul>` 列表元素开始匹配，而原始定位器匹配的是 `<li>` 列表项。

```python
# ✖ WRONG
expect(
    page.get_by_role("listitem").filter(
        has=page.get_by_role("list").get_by_role("heading", name="Product 2")
    )
).to_have_count(1)
```

### 通过不包含子元素/后代元素过滤

我们还可以按 **不包含** 匹配元素进行过滤。

```python
expect(
    page.get_by_role("listitem").filter(
        has_not=page.get_by_role("heading", name="Product 2")
    )
).to_have_count(1)
```

请注意，内部定位器从外部定位器开始匹配，而不是从文档根目录匹配。

## 定位器运算符

### 在定位器内部匹配

你可以链式调用创建定位器的方法，例如 [page.get_by_text()](https://playwright.cn/python/docs/api/class-page#page-get-by-text) 或 [locator.get_by_role()](https://playwright.cn/python/docs/api/class-locator#locator-get-by-role)，以将搜索范围缩小到页面的特定部分。

在此示例中，我们首先通过定位其角色为 `listitem` 来创建名为 product 的定位器。然后我们按文本进行过滤。我们可以再次使用 product 定位器来按角色定位按钮并单击它，然后使用断言来确保只有一个文本为“Product 2”的产品。

```python
product = page.get_by_role("listitem").filter(has_text="Product 2")

product.get_by_role("button", name="Add to cart").click()
```

您还可以将两个定位器链式调用在一起，例如在特定对话框中查找“保存”按钮

```py
save_button = page.get_by_role("button", name="Save")
# ...
dialog = page.get_by_test_id("settings-dialog")
dialog.locator(save_button).click()
```

### 同时匹配两个定位器

[locator.and_()](https://playwright.cn/python/docs/api/class-locator#locator-and) 方法通过匹配额外的定位器来缩小现有定位器的范围。例如，你可以组合使用 [page.get_by_role()](https://playwright.cn/python/docs/api/class-page#page-get-by-role) 和 [page.get_by_title()](https://playwright.cn/python/docs/api/class-page#page-get-by-title) 来同时通过角色和标题进行匹配。

```py
button = page.get_by_role("button").and_(page.get_by_title("Subscribe"))
```

### 匹配两个替代定位器中的一个

如果你想针对两个或多个元素中的某一个，但又不知道具体是哪一个，请使用 [locator.or_()](https://playwright.cn/python/docs/api/class-locator#locator-or) 创建一个匹配其中任意一个或两个替代项的定位器。

例如，考虑一个您想点击“新电子邮件”按钮的场景，但有时会显示安全设置对话框。在这种情况下，您可以等待“新电子邮件”按钮或对话框，并根据情况采取行动。

> [!caution]
>
> 如果屏幕上同时出现“New email”按钮和安全对话框，“or”定位器将同时匹配两者，这可能会抛出 [“严格模式冲突”错误](https://playwright.cn/python/docs/locators#strictness)。在这种情况下，你可以使用 [locator.first](https://playwright.cn/python/docs/api/class-locator#locator-first) 仅匹配其中一个。

```python
new_email = page.get_by_role("button", name="New")
dialog = page.get_by_text("Confirm security settings")
expect(new_email.or_(dialog).first).to_be_visible()
if (dialog.is_visible()):
  page.get_by_role("button", name="Dismiss").click()
new_email.click()
```

### 仅匹配可见元素

> [!caution]
>
> 通常最好找到一种 [更可靠的方法](https://playwright.cn/python/docs/locators#quick-guide) 来唯一标识元素，而不是检查可见性。

考虑一个包含两个按钮的页面，第一个不可见，第二个 [可见](https://playwright.cn/python/docs/actionability#visible)。

```html
<button style="display: none">Invisible</button> <button>Visible</button>
```

- 这将找到两个按钮并抛出 [严格模式](https://playwright.cn/python/docs/locators#strictness) 冲突错误

```python
page.locator("button").click()
```

- 这将只找到第二个按钮，因为它可见，然后点击它。

```python
page.locator("button").filter(visible=True).click()
```

## 列表

### 计算列表中的项目数

您可以断言定位器以统计列表中的项目数。


```html
<ul>
  <li>apple</li>
  <li>banana</li>
  <li>orange</li>
</ul>
```

使用计数断言来确保列表有 3 个项目。

```py
expect(page.get_by_role("listitem")).to_have_count(3)
```

### 断言列表中的所有文本

您可以断言定位器以查找列表中所有文本。


```html
<ul>
  <li>apple</li>
  <li>banana</li>
  <li>orange</li>
</ul>
```

使用 [expect(locator).to_have_text()](https://playwright.cn/python/docs/api/class-locatorassertions#locator-assertions-to-have-text) 确保列表包含文本 “apple”、“banana” 和 “orange”。

```python
expect(page.get_by_role("listitem")).to_have_text(["apple", "banana", "orange"])
```

### 获取特定项目

有多种方法可以获取列表中的特定项目。

#### 通过文本获取

使用 [page.get_by_text()](https://playwright.cn/python/docs/api/class-page#page-get-by-text) 方法通过文本内容定位列表中的元素，然后点击它。

```html
<ul>
  <li>apple</li>
  <li>banana</li>
  <li>orange</li>
</ul>
```

按其文本内容定位项目并点击它。

```python
page.get_by_text("orange").click()
```

#### 通过文本过滤

使用 [locator.filter()](https://playwright.cn/python/docs/api/class-locator#locator-filter) 定位列表中的特定项。

```html
<ul>
  <li>apple</li>
  <li>banana</li>
  <li>orange</li>
</ul>
按“listitem”角色定
```

按“listitem”角色定位项目，然后按“orange”文本过滤，然后点击它。

```python
page.get_by_role("listitem").filter(has_text="orange").click()
```

#### 通过测试 ID 获取

使用 [page.get_by_test_id()](https://playwright.cn/python/docs/api/class-page#page-get-by-test-id) 方法定位列表中的元素。如果还没有测试 ID，你可能需要修改 HTML 并添加一个测试 ID。

```html
<ul>
  <li data-testid="apple">apple</li>
  <li data-testid="banana">banana</li>
  <li data-testid="orange">orange</li>
</ul>
```

按其测试 ID“orange”定位项目，然后点击它。

```python
page.get_by_test_id("orange").click()
```

#### 获取第 N 个项目

如果你有一组相同的元素，且区分它们的唯一方法是顺序，你可以使用 [locator.first](https://playwright.cn/python/docs/api/class-locator#locator-first)、[locator.last](https://playwright.cn/python/docs/api/class-locator#locator-last) 或 [locator.nth()](https://playwright.cn/python/docs/api/class-locator#locator-nth) 从列表中选择特定元素。

```python
banana = page.get_by_role("listitem").nth(1)
```

但是，请谨慎使用此方法。通常情况下，页面可能会发生变化，定位器将指向与您预期完全不同的元素。相反，请尝试构建一个能够通过 [严格模式标准](https://playwright.cn/python/docs/locators#strictness) 的唯一定位器。

### 链式过滤

当你有具有各种相似之处的元素时，你可以使用 [locator.filter()](https://playwright.cn/python/docs/api/class-locator#locator-filter) 方法选择正确的元素。你还可以链式调用多个过滤器来缩小选择范围。

```html
<ul>
  <li>
    <div>John</div>
    <div><button>Say hello</button></div>
  </li>
  <li>
    <div>Mary</div>
    <div><button>Say hello</button></div>
  </li>
  <li>
    <div>John</div>
    <div><button>Say goodbye</button></div>
  </li>
  <li>
    <div>Mary</div>
    <div><button>Say goodbye</button></div>
  </li>
</ul>
```

截取带有“玛丽”和“说再见”的行的屏幕截图

```python
row_locator = page.get_by_role("listitem")

row_locator.filter(has_text="Mary").filter(
    has=page.get_by_role("button", name="Say goodbye")
).screenshot(path="screenshot.png")
```

您现在应该在项目根目录中有一个“screenshot.png”文件。

### 罕见用例

#### 对列表中的每个元素执行操作

迭代元素

```python
for row in page.get_by_role("listitem").all():
    print(row.text_content())
```

使用常规 for 循环迭代

```python
rows = page.get_by_role("listitem")
count = rows.count()
for i in range(count):
    print(rows.nth(i).text_content())
```

#### 在页面中求值

[locator.evaluate_all()](https://playwright.cn/python/docs/api/class-locator#locator-evaluate-all) 内部的代码在页面中运行，你可以在其中调用任何 DOM API。

```python
rows = page.get_by_role("listitem")
texts = rows.evaluate_all("list => list.map(element => element.textContent)")
```

## 严格模式

定位器是严格的。这意味着所有对定位器进行的操作，如果暗示某个目标 DOM 元素，当有多个元素匹配时将抛出异常。例如，如果 DOM 中有多个按钮，则以下调用将抛出异常

#### 当匹配到多个元素时抛出错误

```python
page.get_by_role("button").click()
```

另一方面，Playwright 了解您何时执行多元素操作，因此当定位器解析为多个元素时，以下调用可以正常工作。

#### 处理多个元素时工作正常

```python
page.get_by_role("button").count()
```

你可以通过使用 [locator.first](https://playwright.cn/python/docs/api/class-locator#locator-first)、[locator.last](https://playwright.cn/python/docs/api/class-locator#locator-last) 和 [locator.nth()](https://playwright.cn/python/docs/api/class-locator#locator-nth) 明确告诉 Playwright 在多个元素匹配时使用哪个元素，从而显式地退出严格模式检查。**不推荐** 使用这些方法，因为当页面发生变化时，Playwright 可能会点击你并不想点击的元素。请遵循上述最佳实践来创建能够唯一标识目标元素的定位器。
