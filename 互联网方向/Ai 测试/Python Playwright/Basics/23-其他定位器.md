# [其他定位器](https://playwright.cn/python/docs/other-locators)

## [简介](https://playwright.cn/python/docs/other-locators#%E7%AE%80%E4%BB%8B)

> [!note]
> 查看主要的 [定位器指南](https://playwright.cn/python/docs/locators) 以了解最常用和推荐的定位器。

除了像 `page.get_by_role()` 和 `page.get_by_text()` 这样推荐的定位器之外，Playwright 还支持本指南中描述的各种其他定位器。

---

## [CSS 定位器](https://playwright.cn/python/docs/other-locators#css-%E5%AE%9A%E4%BD%8D%E7%AC%A6)

> [!note]
> 我们建议优先使用诸如文本或可访问角色之类的用户可见的定位器，而不是使用与实现绑定且在页面更改时可能会失效的 CSS。

Playwright 可以通过 CSS 选择器定位元素。

```python
page.locator("css=button").click()

```

Playwright 通过两种方式增强了标准 CSS 选择器：

* CSS 选择器穿透开放的 Shadow DOM。
* Playwright 添加了自定义伪类，例如 `:visible`、`:has-text()`、`:has()`、`:is()`、`:nth-match()` 等。

### [CSS：按文本匹配](https://playwright.cn/python/docs/other-locators#css-%E6%8C%89%E6%96%87%E6%9C%AC%E5%8C%B9%E9%85%8D)

Playwright 包含许多 CSS 伪类，用于根据其文本内容匹配元素。

* **`article:has-text("Playwright")`**：`:has-text()` 匹配包含指定文本的任何元素，即使该文本位于子元素或后代元素中。匹配不区分大小写，会去除多余空格并搜索子字符串。例如，`article:has-text("Playwright")` 匹配 `<article><div>Playwright</div></article>`。

> [!note]
> `:has-text()` 应与其他 CSS 指定符一起使用，否则它将匹配所有包含指定文本的元素，包括 `<body>`。

```python
# Wrong, will match many elements including <body>
page.locator(':has-text("Playwright")').click()

# Correct, only matches the <article> element
page.locator('article:has-text("All products")').click()

```

* **`#nav-bar :text("Home")`**：`:text()` 伪类匹配包含指定文本的最小元素。匹配不区分大小写，修剪空白并搜索子字符串。

```python
page.locator("#nav-bar :text('Home')").click()

```

* **`#nav-bar :text-is("Home")`**：`:text-is()` 伪类匹配具有精确文本的最小元素。精确匹配区分大小写，修剪空白并搜索完整字符串。
例如，`:text-is("Log")` 不匹配 `<button>Log in</button>`，因为 `<button>` 包含一个文本节点 `"Log in"`，它不等于 `"Log"`。但是，`:text-is("Log")` 匹配 `<button> Log <span>in</span></button>`，因为 `<button>` 包含一个文本节点 `" Log "`。
* **`#nav-bar :text-matches("reg?ex", "i")`**：`:text-matches()` 伪类可以匹配文本内容符合 JavaScript 正则表达式的最小元素。例如，`:text-matches("Log\s*in", "i")` 匹配 `<button>Login</button>` 和 `<button>log IN</button>`。

> [!note]
>
> * 文本匹配始终规范化空白。例如，它将多个空格转换为一个，将换行符转换为空格，并忽略前导和尾随空白。
> * 类型为 `button` 和 `submit` 的输入元素按其 `value` 而不是文本内容匹配。例如，`:text("Log in")` 匹配 `<input type=button value="Log in">`。
>
>

### [CSS：仅匹配可见元素](https://playwright.cn/python/docs/other-locators#css-%E4%BB%85%E5%8C%B9%E9%85%8D%E5%8F%AF%E8%A7%81%E5%85%83%E7%B4%A0)

Playwright 支持 CSS 选择器中的 `:visible` 伪类。例如，`css=button` 匹配页面上的所有按钮，而 `css=button:visible` 只匹配可见的按钮。

```html
<button style="display: none">Invisible</button>
<button>Visible</button>
```

```python
# 这将找到两个按钮并抛出严格性违规错误
page.locator("button").click()

# 这将只找到第二个按钮，因为它可见，然后点击它
page.locator("button:visible").click()

```

### [CSS：包含其他元素的元素](https://playwright.cn/python/docs/other-locators#css-%E5%8C%85%E5%90%AB%E5%85%B6%E4%BB%96%E5%85%83%E7%B4%A0%E7%9A%84%E5%85%83%E7%B4%A0)

`:has()` 伪类是一个 CSS 伪类。如果作为参数传递的选择器相对于给定元素的 `:scope` 至少匹配一个元素，它就会返回该元素。

```python
page.locator("article:has(div.promo)").text_content()

```

### [CSS：匹配符合任一条件的元素](https://playwright.cn/python/docs/other-locators#css-%E5%8C%B9%E9%85%8D%E5%85%B6%E4%B8%AD%E4%B8%80%E4%B8%AA%E6%9D%A1%E4%BB%B6%E7%9A%84%E5%85%83%E7%B4%A0)

逗号分隔的 CSS 选择器列表将匹配所有可以由该列表中某个选择器选择的元素。

```python
# Clicks a <button> that has either a "Log in" or "Sign in" text.
page.locator('button:has-text("Log in"), button:has-text("Sign in")').click()

```

### [CSS：基于布局匹配元素](https://playwright.cn/python/docs/other-locators#css-%E5%9F%BA%E4%BA%8E%E5%B8%83%E5%B1%80%E5%8C%B9%E9%85%8D%E5%85%83%E7%B4%A0)

> [!caution]
> 布局选择器已弃用，未来可能会被移除。基于布局的匹配可能会产生意外的结果。

* `:right-of(div > button)` - 匹配位于任何匹配内部选择器的元素右侧的元素。
* `:left-of(div > button)` - 匹配位于任何匹配内部选择器的元素左侧的元素。
* `:above(div > button)` - 匹配位于任何匹配内部选择器的元素上方的元素。
* `:below(div > button)` - 匹配位于任何匹配内部选择器的元素下方的元素。
* `:near(div > button)` - 匹配靠近（50 CSS 像素以内）任何匹配内部选择器的元素的元素。

```python
# Fill an input to the right of "Username".
page.locator("input:right-of(:text(\"Username\"))").fill("value")

# Click a button near the promo card.
page.locator("button:near(.promo-card)").click()

# Click the radio input in the list closest to the "Label 3".
page.locator("[type=radio]:left-of(:text(\"Label 3\"))").first.click()

```

### [CSS：从查询结果中选取第 n 个匹配项](https://playwright.cn/python/docs/other-locators#css-%E4%BB%8E%E6%9F%A5%E8%AF%A2%E7%BB%93%E6%9E%9C%E4%B8%AD%E9%80%89%E2%80%8B%E6%8B%A9%E7%AC%AC-n-%E4%B8%AA%E5%8C%B9%E9%85%8D%E9%A1%B9)

`:nth-match(:text("Buy"), 3)` 将选择符合条件的第三个按钮（索引从 1 开始）。

```python
# Click the third "Buy" button
page.locator(":nth-match(:text('Buy'), 3)").click()

# Wait until all three buttons are visible
page.locator(":nth-match(:text('Buy'), 3)").wait_for()

```

## [第 N 个元素定位器](https://playwright.cn/python/docs/other-locators#%E7%AC%AC-n-%E4%B8%AA%E5%85%83%E7%B4%A0%E5%AE%9A%E4%BD%8D%E7%AC%A6)

您可以使用 `nth=` 定位符将查询缩小到第 n 个匹配项，传递一个从零开始的索引。

```python
# Click first button
page.locator("button").locator("nth=0").click()

# Click last button
page.locator("button").locator("nth=-1").click()

```

## [父元素定位器](https://playwright.cn/python/docs/other-locators#%E7%88%B6%E5%85%83%E7%B4%A0%E5%AE%9A%E4%BD%8D%E7%AC%A6)

当需要定位某个其他元素的父元素时，使用 `locator.filter()` 效果最好：

```python
child = page.get_by_text("Hello")
parent = page.get_by_role("listitem").filter(has=child)

```

或者使用 `xpath=..`：

```python
parent = page.get_by_text("Hello").locator('xpath=..')

```

## [XPath 定位器](https://playwright.cn/python/docs/other-locators#xpath-%E5%AE%9A%E4%BD%8D%E7%AC%A6)

```python
page.locator("xpath=//button").click()

```

> [!note]
>
> * 任何以 `//` 或 `..` 开头的选择器字符串都被认为是 xpath 选择器。
> * XPath 不会穿透 Shadow DOM。
>
>

### [XPath 并集](https://playwright.cn/python/docs/other-locators#xpath-%E8%81%94%E5%90%88)

```python
# Waits for either confirmation dialog or load spinner.
page.locator("//span[contains(@class, 'spinner__loading')]|//div[@id='confirmation']").wait_for()

```

## [Label 到表单控件的重定向定位](https://playwright.cn/python/docs/other-locators#%E6%A0%87%E7%AD%BE%E5%88%B0%E8%A1%A8%E5%8D%95%E6%8E%A7%E4%BB%B6%E7%9A%84%E9%87%8D%E5%AE%9A%E5%90%91)

你可以使用 `page.get_by_text()` 通过标签文本定位 label，Playwright 会自动将输入操作作用于关联的控件：

```python
# Fill the input by targeting the label.
page.get_by_text("Password").fill("secret")

```

## [遗留文本定位器](https://playwright.cn/python/docs/other-locators#%E4%BC%A0%E7%BB%9F%E6%96%87%E6%9C%AC%E5%AE%9A%E4%BD%8D%E7%AC%A6)

```python
page.locator("text=Log in").click()
page.locator("text='Log in'").click()
page.locator("text=/Log\s*in/i").click()

```

## [id, data-testid, data-test-id, data-test 选择器](https://playwright.cn/python/docs/other-locators#id-data-testid-data-test-id-data-test-%E9%80%89%E6%8B%A9%E5%99%A8)

```python
# Fill an input with the id "username"
page.locator('id=username').fill('value')

# Click an element with data-test-id "submit"
page.locator('data-test-id=submit').click()

```

## [链式选择器](https://playwright.cn/python/docs/other-locators#%E9%93%BE%E5%BC%8F%E9%80%89%E6%8B%A9%E5%99%A8)

使用 `>>` 组合多个选择器：

```python
css=article >> css=.bar > .baz >> css=span[attr=value]

```

### [中间匹配项](https://playwright.cn/python/docs/other-locators#%E4%B8%AD%E9%97%B4%E5%8C%B9%E9%85%8D%E9%A1%B9)

在选择器前加上 `*` 可以捕获由中间选择器查询到的元素：

```python
*css=article >> text=Hello

```
