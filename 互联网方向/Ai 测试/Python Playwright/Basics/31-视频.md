# 视频录制

## 简介

使用 [Playwright Python](https://playwright.cn/python/) 可以为你的自动化测试录制视频。

---

## 录制视频

视频会在测试结束时随 [浏览器上下文 (BrowserContext)](https://playwright.cn/python/docs/browser-contexts) 的关闭而自动保存。如果您手动创建了浏览器上下文，请确保调用 [browser_context.close()](https://playwright.cn/python/docs/api/class-browsercontext#browser-context-close)。

### 1. 基本配置

设置视频保存目录：

**同步 (Sync)**

```python
context = browser.new_context(record_video_dir="videos/")
# 务必关闭上下文以确保视频成功保存
context.close()

```

**异步 (Async)**

```python
context = await browser.new_context(record_video_dir="videos/")
# 务必关闭上下文以确保视频成功保存
await context.close()

```

---

### 2. 自定义视频尺寸

视频尺寸默认会按比例缩小以适应 $800 \times 800$ 的视口。您可以通过 `record_video_size` 参数显式指定输出视频的宽高尺寸：

**同步 (Sync)**

```python
context = browser.new_context(
    record_video_dir="videos/",
    record_video_size={"width": 640, "height": 480}
)

```

**异步 (Async)**

```python
context = await browser.new_context(
    record_video_dir="videos/",
    record_video_size={"width": 640, "height": 480}
)

```

---

### 3. 获取视频路径

保存的视频文件会生成唯一的随机文件名并存储在指定的文件夹中。对于多页面场景，可以通过 [page.video](https://playwright.cn/python/docs/api/class-page#page-video) 获取当前页面对应的视频文件路径：

**同步 (Sync)**

```python
path = page.video.path()

```

**异步 (Async)**

```python
path = await page.video.path()

```

> **注意**：视频文件仅在页面或浏览器上下文彻底关闭后才可正常读取和使用。
